# Fontes

As fontes são servidas localmente, com `font-display: swap`, sem requisições a Google Fonts durante a navegação.

- **Sora**, variável, pesos 500–700: [Google Fonts](https://fonts.google.com/specimen/Sora), WOFF2 latino de 25.284 bytes. Peso 600 nos títulos principais, seções e cursos. [Licença SIL Open Font License](../public/assets/Sora-OFL.txt).
- **Manrope**, variável, pesos 400–700: [Google Fonts](https://fonts.google.com/specimen/Manrope), WOFF2 latino de 24.836 bytes. Utilizada nos parágrafos, menus, botões, legendas, endereço e rodapé. [Licença SIL Open Font License](../public/assets/Manrope-OFL.txt).

Os dois arquivos somam 50.120 bytes. Os arquivos anteriores de Instrument Serif foram removidos. Não há fonte itálica adicional; os destaques dos títulos usam cor. Fallback: Arial/sans-serif. O conteúdo mantém sua legibilidade se as fontes não carregarem. A logo e as letras incorporadas às imagens oficiais permanecem intactas.
